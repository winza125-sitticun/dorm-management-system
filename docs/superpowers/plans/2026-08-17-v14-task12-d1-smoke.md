# V14 Task 12 D1 Smoke Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prove the V14 customer candidate can complete a real Cloudflare Pages + D1 backup/restore cycle while preserving current integrations, logging restore audit evidence, and enforcing Demo restore restrictions.

**Architecture:** A GitHub Actions workflow downloads the immutable candidate artifact from successful source-gate run `31980850645`, extracts the Pro customer ZIP, creates disposable Cloudflare Pages and D1 resources, deploys the package, and runs a Python smoke harness against the deployed API plus remote D1. The harness stores only sanitized hashes, counts, booleans, and resource names; GitHub/Cloudflare tokens, JWTs, restore tokens, LINE secrets, and Google refresh tokens are never written to artifacts. Cleanup runs with `if: always()` and removes the temporary Pages project and D1 database.

**Tech Stack:** GitHub Actions, Node.js 22, Wrangler 4.x from the candidate package, Python 3 standard library, Cloudflare Pages, Cloudflare D1.

## Global Constraints

- Cloudflare credentials come only from GitHub Secrets `CLOUDFLARE_API_TOKEN` and `CLOUDFLARE_ACCOUNT_ID`.
- Backup archive format remains `dorm-backup`, `formatVersion=1`, `schemaVersion=6`.
- Restore confirmation text is exactly `RESTORE`.
- Backup/Validate/Restore responses must remain `Cache-Control: no-store`.
- Demo backup export must succeed; Demo restore must fail with HTTP 403 and error code `PLAN_REQUIRED`.
- Restore must preserve current room LINE linkage, LINE settings, Google spreadsheet ID, and Google OAuth refresh token.
- Evidence must not contain Cloudflare API token, JWT, restore token, LINE channel token/secret, or Google OAuth refresh token.

```python
class SmokeHelpersTest(unittest.TestCase):
    def test_extract_api_data_requires_success(self):
        self.assertEqual(smoke.extract_api_data({"success": True, "data": {"x": 1}}), {"x": 1})
        with self.assertRaises(smoke.SmokeFailure):
            smoke.extract_api_data({"success": False, "error": {"code": "X"}})

    def test_build_wrangler_config_replaces_only_placeholders(self):
        template = '{"name":"REPLACE_WITH_YOUR_PAGES_PROJECT","d1_databases":[{"binding":"DB","database_name":"REPLACE_WITH_YOUR_D1_DATABASE","database_id":"00000000-0000-0000-0000-000000000000"}]}'
        rendered = smoke.build_wrangler_config(template, "pages-test", "db-test", "11111111-1111-1111-1111-111111111111")
        self.assertIn('"name":"pages-test"', rendered)
        self.assertIn('"database_name":"db-test"', rendered)
        self.assertIn('"database_id":"11111111-1111-1111-1111-111111111111"', rendered)
        self.assertNotIn("REPLACE_WITH_YOUR", rendered)

    def test_sanitize_evidence_blocks_secret_keys(self):
        evidence = {"jwt": "bad", "restoreToken": "bad", "lineSecret": "bad", "ok": True}
        clean = smoke.sanitize_evidence(evidence)
        self.assertEqual(clean, {"ok": True})

    def test_assert_no_store(self):
        smoke.assert_no_store({"cache-control": "no-store"}, "backup export")
        with self.assertRaises(smoke.SmokeFailure):
            smoke.assert_no_store({"cache-control": "public"}, "backup export")
```

The workflow must:

1. Fail closed if either Cloudflare secret is empty, printing only the missing secret name.

3. Run `npm ci` in `smoke-work`.
4. Generate unique lowercase resource names from `GITHUB_RUN_ID` and `GITHUB_RUN_ATTEMPT` within Cloudflare naming limits.
